## Phase 2 — 2A Workflow Pro, 2B Intelligence, 2C Polish

The Flutter source implements the plan's local workflow and platform-independent items without a database schema change. Workflow metadata remains in app-private JSON and email data remains in Drift. This is an implementation record, not a claim of live-provider or cross-platform verification.

- **2A Workflow Pro:** sender screening hides matching mail in GlassMail without deleting it or creating a Gmail filter. Snooze and follow-up metadata survive relaunch; due mail is surfaced in Inbox. Templates preserve user-authored subject/body, saved views use local FTS search, and there is no app-level account-count cap. Android scheduled sends use unique network-constrained WorkManager jobs with approximate execution; iOS sends are foreground-only, pause when backgrounded, and interrupted sends return as drafts.
- **2B Intelligence:** storage advisor, configured cache enforcement, manual cleanup, deterministic local smart cards, and generic-by-default notifications are implemented. AI summaries are not included: official Apple Foundation Models and Android ML Kit GenAI availability is device/region constrained and does not establish a model available across GlassMail's supported targets ([Apple Foundation Models](https://developer.apple.com/documentation/FoundationModels), [Apple availability guidance](https://developer.apple.com/documentation/FoundationModels/generating-content-and-performing-tasks-with-foundation-models), [Google ML Kit GenAI](https://developers.google.com/ml-kit/genai), [Android Prompt API requirements](https://developers.google.com/ml-kit/genai/prompt/android/get-started)).
- **2C Polish:** generic local snooze/follow-up notifications, confirmed HTTP(S) external links, user-invoked Contacts picker for sender display names, Compose/Inbox/Search launcher shortcuts, encrypted `.gmbak` export/import, and native unread-count home-screen widget sources are implemented. Backups use PBKDF2-HMAC-SHA256 (600,000 iterations) and AES-256-GCM, include the local database/attachment bytes/workflow and appearance preferences, and restore only into an empty database. Credentials, queued provider mutations, and scheduled-send jobs are excluded; accounts require credentials again after restore.
